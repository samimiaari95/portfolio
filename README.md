# Sami Miaari — Career Profile

A lightweight, accessible career profile built as a static site for GitHub Pages. The expertise selector presents detailed evidence across applied machine learning, hydrology, geospatial data engineering, delivery, environmental systems, and scientific communication.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site from the `main` branch after each push. In the repository settings, choose **Pages → Build and deployment → GitHub Actions** if Pages has not been configured for the repository yet.

## Content

Professional details are based on the CV and experience materials supplied for this profile. Personal contact details and private application correspondence are not included. Research manuscripts are described as under peer review, not as published work.
